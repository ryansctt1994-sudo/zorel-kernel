# Security Policy

Cathedral OS is an early-stage research and engineering scaffold. Do not use it as a production security boundary without independent review.

## Reporting

Please report security issues through GitHub issues until a private disclosure channel is configured. Do not include live credentials, private keys, or sensitive production data in public reports.

## Scope

Relevant reports include:

- authority bypass;
- nondeterministic receipt generation;
- witness record tampering;
- replay mismatch;
- unsafe default behavior;
- documentation that overstates evidence level.

## Evidence expectation

Security reports should include reproduction steps, observed behavior, expected behavior, and affected commit when possible.
